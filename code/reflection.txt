I began this assignment unsure of the different merge/join types and their
uses. Through this assignment I learned that a left merge keeps every row
of the left frame, which helped for this assignment because I needed to ensure
that an employee (who was E099 in this case) that was not on the roster
would still be included in the payroll. I figured out that the default inner
merge without how= would not have resulted in an error, and instead would
have just run and dropped the employee (which means the employee just does
not get paid). This is what makes the debugging here important.

I used Series.apply in add_hours_worked to turn each value in the hours column
(like "38h 30m") into a number (38.5), because parse_hours only needs one
value. I had to alter it for gross pay, since calc_gross_pay needs two values
from the same row (hours_worked and hourly_rate_usd). So, I used row apply with
axis=1, which passes the lambda one row at a time instead of whole columns.
